## What We Build

### FF-Terminal v3.0
Enterprise-grade autonomous AI terminal with dual orchestration architecture.

**Core Capabilities:**
- Dual orchestration: Simple (90% parallel) and Hierarchical (10% complex planning)
- 43 integrated tools with natural language interface
- 8 AI provider support for flexibility and cost optimization
- State persistence with SQLite-backed checkpointing
- Completion validation engine with 176+ NLP patterns
- Skills system for on-demand capability extension
- Mood system for runtime personality switching
- 4 operation modes: auto, confirm, read_only, planning

**Performance:**
- Session duration: 10+ hours
- Tool call capacity: 5,000+
- Tool call success rate: 95-99%
- Average orchestration time: 5.2s (simple), 18.7s (hierarchical)

### AgentSkills.io Farming Library
Open source agricultural skills in AgentSkills.io format, designed for autonomous AI assistants.

**Purpose:**
- Provide farmers with reusable AI skills
- Automate agricultural operations
- Support natural farming methods (JADAM)
- Enable community contribution and collaboration

## Directives

### Technology Principles
- **Autonomous-first:** Build systems that operate independently
- **State persistence:** Enable hours-long workflows with recovery
- **Multi-provider flexibility:** Optimize for cost and performance
- **Validation-driven:** Ensure promises are fulfilled
- **Skills-based:** Extend capabilities dynamically

### Farming Principles
- **Natural methods:** Prioritize JADAM and regenerative practices
- **Data-driven:** Use weather, sensors, and historical data
- **Rehabilitation-focused:** Restore and improve land health
- **Sustainable:** Reduce chemical inputs, build soil health
- **Practical:** Solve real farming problems, not theoretical

### Open Source Principles
- **Community-driven:** Share knowledge and build ecosystem
- **Transparent:** Open code and documentation
- **Collaborative:** Welcome contributions from farmers and developers
- **Accessible:** Free to use, modify, and distribute
- **Quality-focused:** Test skills and validate functionality
